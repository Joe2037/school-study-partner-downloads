# School Study Partner downloads

Official beta installer downloads for School Study Partner, published by Joseph Canova.

Choose your computer and read installation guidance at [schoolstudypartner.com](https://schoolstudypartner.com/pages/study-partner-downloads).

This repository contains distributable apps, checksums and release information. The development source repository and student libraries are not uploaded here.

Current desktop downloads are unsigned betas. Mac apps are not notarized. Review the release notes and testing limitations before installing; school-managed computers may need IT approval. Do not disable security protections.
